# Contributing

Thanks for helping smallholder farmers get affordable tools.

- Keep it **standard-library only** so it installs on a phone with no compiling.
- Run `python -m unittest discover -v` before opening a pull request.
- Good first contributions: translations (isiZulu, isiXhosa, Sesotho, Setswana, Sepedi) in `plaaskit/alerts.py`,
  more crop coefficients in `plaaskit/water.py`, region-specific alert thresholds, and field-tested feedback.
- Alert thresholds are advisory defaults. If you are an agronomist and can improve them for a crop or region, please
  open an issue with a source.
